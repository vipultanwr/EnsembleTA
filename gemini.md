### Project Goal
EnsembleTA's main objective is to create a robust, ensemble trading strategy by identifying the best-performing technical indicators from a vast pool, and then validating the combined strategy on out-of-sample data.

### Methodology
The workflow is divided into two distinct phases:

1.  **Ranking Phase (In-Sample):**
    *   A large number of technical analysis strategies are generated using the `TA-Lib` library.
    *   Each strategy is backtested individually (in both "forward" and "reverse" variations) over a specific historical "ranking" period.
    *   They are ranked based on performance metrics suchs as final return, Sharpe ratio, and profit factor.
    *   The top-performing strategies are selected and saved for the next phase.

2.  **Ensemble Backtesting Phase (Out-of-Sample):**
    *   The top strategies identified in the ranking phase are used to form an "ensemble."
    *   A final signal is generated by aggregating the signals from these top strategies (a form of "voting").
    *   This ensemble strategy is then rigorously backtested on a separate, unseen "out-of-sample" dataset to evaluate its real-world effectiveness.

### Key Technologies & Structure
*   **Libraries:** `pandas` for data handling, `fastquant` for fetching crypto data, and `talib` for technical indicators.
*   **Custom Utilities:** The project relies on a custom library, `CoreQuantUtilities`, for core functionalities like the `StrategyBacktester` and the `getTACombinedSignals` function.
*   **Evolution:** The project started with exploratory analysis in Jupyter Notebooks (`notebooks/`) and is now being refactored into a more structured and reusable format using Python scripts (`ensemble_backtest.py`, `config.py`, etc.).
