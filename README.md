# Ensemble Trading Strategy Backtester

This project implements and evaluates an ensemble trading strategy based on a large set of technical indicators from the TA-Lib library. The goal is to identify the best-performing indicators, combine them into a unified strategy, and validate its performance on out-of-sample cryptocurrency data.

## Project Overview

The methodology is divided into two main phases:

1.  **Ranking Phase (In-Sample)**: The system first evaluates a wide range of individual technical analysis strategies over a historical "ranking" period. It tests both "forward" (long) and "reverse" (short) versions of each strategy and ranks them based on performance metrics like final return and Sharpe ratio. The top performers are selected for the next phase.

2.  **Ensemble Backtesting (Out-of-Sample)**: The top-ranked strategies are combined into an "ensemble." A final trading signal is generated by aggregating the signals from these strategies (a "voting" system). This final ensemble strategy is then rigorously backtested on a separate, unseen "out-of-sample" dataset to validate its effectiveness and robustness.

## Setup and Installation

To set up the project, you can use either Conda or Pip.

### Using Conda (Recommended)

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd <repository-name>
    ```

2.  **Create the Conda environment:**
    This command creates a new environment named `project1` with all the necessary dependencies.
    ```bash
    conda env create -f environment.yml
    ```

3.  **Activate the environment:**
    ```bash
    conda activate project1
    ```

### Using Pip

1.  **Clone the repository and create a virtual environment:**
    ```bash
    git clone <repository-url>
    cd <repository-name>
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```

2.  **Install the dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

## How to Run

Once the environment is set up and activated, you can run the full ranking and backtesting process with the following command:

```bash
python ensemble_backtest.py
```

The script will:
1.  Load data for the ranking period specified in `config.py`.
2.  Generate and rank all technical analysis strategies.
3.  Print the top-performing forward and reverse strategies.
4.  Save the top strategies to `.pkl` files.
5.  Run a final out-of-sample backtest using the ensemble of top strategies.
6.  Print the final performance metrics and display a plot of the results.
