# GEMINI.md

## Project Overview

This project implements and evaluates an ensemble trading strategy for cryptocurrencies based on a large set of technical indicators from the TA-Lib library. The primary goal is to identify the best-performing indicators, combine them into a unified strategy, and validate its performance on out-of-sample data.

The methodology is divided into two main phases:

1.  **Ranking Phase (In-Sample):** The system evaluates a wide range of individual technical analysis strategies over a historical "ranking" period. It tests both "forward" (long) and "reverse" (short) versions of each strategy and ranks them based on performance metrics like final return and Sharpe ratio. The top performers are selected for the next phase.

2.  **Ensemble Backtesting (Out-of-Sample):** The top-ranked strategies are combined into an "ensemble." A final trading signal is generated by aggregating the signals from these strategies using a "voting" system, facilitated by the `generate_ensemble_signal` function in `src/strategy.py`. This final ensemble strategy is then rigorously backtested on a separate, unseen "out-of-sample" dataset to validate its effectiveness and robustness.

## Building and Running

This project uses `uv` for dependency management and virtual environment creation, combined with `pyenv` for Python version management.

1.  **Install `pyenv` and Python 3.12.1:**
    ```bash
    pyenv install 3.12.1
    ```

2.  **Install `uv`:**
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```

3.  **Set local Python version and create virtual environment:**
    ```bash
    pyenv local 3.12.1
    uv venv
    ```

4.  **Activate the virtual environment:**
    ```bash
    source .venv/bin/activate
    ```

5.  **Install dependencies:**
    ```bash
    uv pip install .
    ```

### Running the Orchestrator

To run multiple backtests for hyperparameter tuning (as defined in `config.yaml`), use the `run_orchestrator.py` script.

```bash
python scripts/run_orchestrator.py
```

This will execute a backtest for each combination of parameters in the `param_grid` defined in `config.yaml` and generate `results/master_results.csv`.

### Generating the Dashboard

After running the orchestrator, you can generate the interactive HTML dashboard.

```bash
python scripts/generate_dashboard.py
```
This will create an `index.html` file in your project root.

## Development Conventions

### Adding a New Strategy

To add a new strategy:

1.  **Copy the Template:**
    Make a copy of `src/strategies/template_strategy.py` and rename it to `src/strategies/your_strategy_name.py`.

2.  **Implement Your Logic:**
    Open the new file and implement your custom logic within the `generate_signals` function. This function should take `data` (a pandas DataFrame with OHLC data) and `**params` as input, and return a pandas DataFrame with a single `signal` column containing your trading signals (-1 for sell, 0 for hold, 1 for buy).

3.  **Configure Your Strategy (Optional):**
    If your strategy has specific parameters, you can add them to `config.yaml` and access them within your `generate_signals` function via the `params` dictionary.

4.  **Run Your Strategy:**
    ```bash
    python scripts/run_backtest.py --strategy your_strategy_name
    ```
